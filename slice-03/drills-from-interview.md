# Real drills — interview draft (Christoffer)

Swedish app terms: gymnaster, pass. Blocks: Samling → Uppvärmning → Teknik → Styrka → Lek och spel.

## Samling

### 1. Välkomstcheck-in
- **Duration:** ~5 min
- **Summary:** Välkomna gruppen och kolla hur veckan har varit.
- **How:** Samla gymnasterna. Hälsa alla. Kort runda: hur mår ni / hur har veckan varit? Håll det kort och inkluderande.
- **Watch for:** Enskilda monologer som äter tiden; se till att tysta gymnaster också får plats utan press.
- **stub:** false (coach-owned)

### 2. Närvaro
- **Duration:** ~2–3 min (confirm later)
- **Summary:** Bocka av listan så att alla som ska vara där är på plats.
- **How:** Gå igenom närvarolistan. Markera närvarande/frånvarande. Följ upp om någon saknas enligt klubbens rutin.
- **Watch for:** Glöm inte avvikande namn/nya gymnaster; lämna inte gruppen utan uppsikt medan du bara stirrar i listan.
- **stub:** false

### 3. Dagens teknik — snabb genomgång
- **Duration:** ~2–3 min (confirm later)
- **Summary:** Kort genomgång av dagens huvudteknik innan uppvärmning/träning.
- **How:** Berätta dagens fokusfärdighet i enkla ord. Visa gärna kort eller peka ut vad ni ska sikta på. Spara djup coaching till Teknik-blocket.
- **Watch for:** För lång teori; håll det till “vad + varför idag”, inte hela övningen.
- **stub:** false

## Uppvärmning

### 4. Uppvärmningsvarv (hallen runt)
- **Duration:** ~8–12 min
- **Summary:** Rörligt varv i hallen med löpning och grundfärdigheter.
- **How:** Led varvet i lagom fart. Ingår typiskt: springa, springa baklänges, ljusstakar (candlesticks) fram och bak, kullerbytta framåt/bakåt, hjulning vänster och höger, bear walk, handstand, handstand till hopkrupen, crocodile walk, kaninhopp (rabbit jumps). Anpassa vilka delar som är med efter nivå och dag.
- **Watch for:** Utrymme och krockar; handstand och bakåtkullerbytta kräver madrass/uppsikt — tvinga inte max om tekniken inte sitter. Hjulning: båda sidorna, kontrollera axlar/handleder.
- **watchForRequired:** true
- **needsCoachReview:** true (handstand / tumbling elements)

### 5. Uppvärmningsdans
- **Duration:** ~5–8 min
- **Summary:** Dansuppvärmning som rör hela kroppen.
- **How:** Sätt på musik. Led eller använd en känd uppvärmningsdans. Mål: axlar, höfter, rygg, ben och koordination — inte maxpuls utan rörlighet och glädje.
- **Watch for:** För vilda hopp på hårt golv; ge alternativ för den som inte vill dansa “sceniskt”.

### 6. 1-2-3 (framerotation / volt-positioner)
- **Duration:** ~3–5 min
- **Summary:** Positionerna 1, 2, 3 inför framåtvolt / frivolt-arbete.
- **How:** Gå igenom och låt gymnasterna öva de tre positionerna som ni använder i klubben för framåtvolt (bekräfta gärna exakt vad 1/2/3 betyder hos er). Kort, rytmiskt, samma språk varje gång.
- **Watch for:** Tydlighet i språket så alla menar samma position; ingen full volt i uppvärmningen om ni bara övar formerna.
- **needsCoachReview:** true (confirm exact club positions)

### 7. Töjning — gymnasterna leder
- **Duration:** ~5 min
- **Summary:** Töjning där gymnasterna leder varandra / gruppen.
- **How:** Utse ledare (rotera). De visar töjningar ni redan kan. Coachen backar upp säkerhet och tid.
- **Watch for:** Ojämn kvalitet — coachen rättar farliga vinklar; ingen “press” djupare än behagligt.

### 8. Töjning — coach leder
- **Duration:** ~5 min
- **Summary:** Coachledd töjning efter eller mitt i uppvärmningen.
- **How:** Led ett kort, förutsägbart stretchprogram (ben, höftböjare, axlar, handleder efter behov). Andas lugnt; håll 15–30 s per sida där det passar.
- **Watch for:** Studsande stretch; smärta ≠ “bra”; anpassa för hypermobila gymnaster.

## Teknik (truppgymnastik)

### 9. Ljushopp på satsbräda
- **Duration:** ~5–8 min
- **Summary:** Ljushopp från satsbräda — grundstuds/hoppteknik.
- **How:** Sats → bräda → ljushopp med kontroll i landning. Fokus på timing och rak kropp, inte höjd först.
- **Watch for:** Fel fotisättning på brädan; landning bakom/framför mattan; köhållning så ingen springer in för tidigt.
- **newCoachOk:** true

### 10. Ljushopp på trampett
- **Duration:** ~5–8 min
- **Summary:** Ljushopp på trampett.
- **How:** Tydlig ansats, studs i mitten av trampetten, sträckt ljushopp, mjuk landning. En i taget.
- **Watch for:** Ansats för lång/snabb; studs nära kanten; landning utan madrasskydd där det behövs.
- **newCoachOk:** true

### 11. Satsbräda volt till rygg
- **Duration:** ~8–10 min
- **Summary:** Volt från satsbräda till landning på rygg (progressiv volt).
- **How:** Satsbräda → rotation → landning på rygg i madrass. Bygg från kort rotation innan fullare volt. Spotting efter nivå.
- **Watch for:** För lite rotation (nacke/huvud); för mycket höjd utan kontroll; madrass måste räcka bakåt.
- **newCoachOk:** true
- **watchForRequired:** true

### 12. Trampett volt upp på mattberg
- **Duration:** ~8–10 min
- **Summary:** Volt från trampett upp på mattberg.
- **How:** Ansats → trampett → volt → landning högt på mattberg. Progressera höjd/rotation. En i taget, tydlig kö.
- **Watch for:** Mattberg stabilt och högt nog; underrotation; att nästa gymnast väntar tills landningen är klar.
- **newCoachOk:** true
- **watchForRequired:** true

### 13. Rondat–flickis
- **Duration:** ~10 min
- **Summary:** Rondat till flickis (bakåtväxel / flic-flac).
- **How:** Endast med erfaren ledare. Progressera från bekanta delar; spotta aktivt.
- **Watch for:** Handplacering, axellinje, underrotation, nacke. Avbryt om tekniken fallerar under setet.
- **newCoachOk:** false
- **experiencedCoachOnly:** true
- **watchForRequired:** true

### 14. Flickis med flickiskudde
- **Duration:** ~8–10 min
- **Summary:** Flickis med flickiskudde som stöd/progressiv hjälp.
- **How:** Använd kudden enligt klubbens metod. Låt gymnasten känna bakåtrörelsen med stöd innan fri flickis.
- **Watch for:** Kudden rätt placerad; inte “kasta” bakåt utan aktivt handstöd från gymnasten där metoden kräver det.
- **newCoachOk:** true
- **watchForRequired:** true

### 15. Falla bakåt från höjd till rygg
- **Duration:** ~5–8 min
- **Summary:** Kontrollerad fall bakåt från höjd till landning på rygg.
- **How:** Från plint/höjd som klubben använder → falla bakåt till rygg i madrass. Bygg trygghet inför bakåtmoment.
- **Watch for:** Huvudet får inte ta emot; madrass tillräckligt tjock/lång; ingen lek “vem vågar högst” utan teknikfokus.
- **newCoachOk:** true
- **watchForRequired:** true

### 16. Salto från höjd
- **Duration:** ~8–10 min
- **Summary:** Salto från höjd (fullare voltmoment).
- **How:** Endast med erfaren ledare och rätt uppbyggnad. Spotting och madrassuppställning före första försöket.
- **Watch for:** Under/överrotation; landningszon; trötthet i kön. Stoppa tidigt vid osäkra försök.
- **newCoachOk:** false
- **experiencedCoachOnly:** true
- **watchForRequired:** true

### 17. Handstående falla till rygg
- **Duration:** ~5–8 min
- **Summary:** Från handstående, kontrollerad fall till rygg.
- **How:** Handstående (mot vägg eller fri enligt nivå) → tippa/falla till rygg i madrass. Lär öppning och trygg bakåtlandning.
- **Watch for:** Huvud/nacke; axlar kollapsar; madrass bakom måste finnas innan de går upp i handstående.
- **newCoachOk:** true
- **watchForRequired:** true

## Styrka

### 18. Cirkelträning (par, stationer)
- **Duration:** ~10–15 min
- **Summary:** Cirkel med flera stationer; gymnaster går runt i par.
- **How:** Sätt 4–8 stationer. 30 sekunder arbete, 20 sekunder vila/byte. Jobba i par. Visa varje station kort innan start. Håll tiden tydligt (timer/musiksignal).
- **Watch for:** Stationer med rätt avstånd; teknik före tempo; anpassa övningar så nybörjare inte tar skadliga genvägar.
- **newCoachOk:** true

### 19. Burpee-challenge (EMOM)
- **Duration:** ~6–10 min
- **Summary:** Burpees EMOM — every minute on the minute.
- **How:** Varje minut: bestämt antal burpees (eller max under resten av minuten enligt vald variant), vila till nästa minutstart. Sätt nivå efter gruppen. Visa korrekt burpee först.
- **Watch for:** Ojämn form när de blir trötta (höfter sjunker, hopp blir slarviga); tillåt regression (step-back / utan hopp).
- **newCoachOk:** true

### 20. Styrkelåtar (Sally, Thunderstruck, Gimme Gimme, jägarvila)
- **Duration:** ~en låt vardera (ca 3–5 min per låt) eller medley
- **Summary:** Styrka till kända låtar — t.ex. Sally ups/squats, Thunderstruck, Gimme Gimme Gimme, jägarvila hela låten.
- **How:** Välj en låt. Förklara rörelsen innan musiken startar. Hela gruppen synkar till refränger/verser enligt er klubbrutin (Sally = upp/ner till texten, Thunderstruck = typiskt burpee/jump-variation, Gimme = vald styrkeövning, jägarvila = holds i jägarvila hela låten).
- **Watch for:** Knän/hållning i squat; axlar i holds; erbjud knästående/kortare hold för dem som behöver. Volym — en eller två låtar räcker ofta i ett pass.
- **newCoachOk:** true

## Lek och spel

### 21. Rundpingis med medicinboll
- **Duration:** ~5–8 min
- **Summary:** Pingis-/rundspel med medicinboll i stället för vanlig boll.
- **How:** Cirkel eller rundpingis-regler ni brukar. Medicinboll (lagom vikt för åldern). Tydliga gränser för hur hårt de får kasta.
- **Watch for:** Ansikte/händer — för tung boll eller hårda kast; anpassa bollvikt.
- **newCoachOk:** true

### 22. Höjdhopp (lek)
- **Duration:** ~5–8 min
- **Summary:** Lekfullt höjdhopp / över ribba eller mjuk höjd.
- **How:** Sätt en säker “ribba” (elastiskt band, moppskaft på koner, eller mjuka mattor). En i taget eller stafettvariant. Höj stegvis.
- **Watch for:** Landning på två fötter i mjuk zon; ingen hård ribba i ansiktshöjd; köordning.
- **newCoachOk:** true

### 23. Stafett
- **Duration:** ~5–10 min
- **Summary:** Klassisk stafett — lag, sträcka, växling.
- **How:** Dela lag. Bestäm bana och vad som bärs/görs vid växling. Demonstrera en gång. Fair start.
- **Watch for:** Hala golv i kurvor; krockar i växling; håll banan fri från redskap.
- **newCoachOk:** true

### 24. 1-2-3 (lek)
- **Duration:** ~3–5 min
- **Summary:** Förflyttningslek: 1 = den framför går bak, 2 = den bak går fram, 3 = spring.
- **How:** Gymnasterna i led/par enligt er uppställning. Ropa 1, 2 eller 3. 1: personen längst fram flyttar sig längst bak. 2: personen längst bak flyttar sig längst fram. 3: alla springer (bestäm vart — t.ex. till linje och tillbaka).
- **Watch for:** Krockar vid 3; tydliga gränser i hallen.
- **newCoachOk:** true
- **note:** Skilt från uppvärmningens “1-2-3” voltpositioner.

### 25. Maffia
- **Duration:** ~8–12 min
- **Summary:** Maffia-lek (social/rollek) enligt klubbens variant.
- **How:** Använd er vanliga Maffia-uppsättning (roller, “natt/dag”, ledare som berättar). Håll det åldersanpassat. *(Christoffer: fyll gärna i exakta roller om ni har en fast variant.)*
- **Watch for:** Uteslutning/önskan — byt roller ofta; ingen fysisk “attack”.
- **newCoachOk:** true
- **needsCoachReview:** true (confirm club rules)

### 26. Handstående-utmaning
- **Duration:** ~5 min
- **Summary:** Lekfull utmaning — vem håller handstående / flest försök med bra form.
- **How:** Mot vägg eller med kompisstöd efter nivå. Mät tid eller antal kontrollerade försök — belöna form, inte bara “vågat”.
- **Watch for:** Fall utan madrass; nacke; tävlingsspöke som gör slarviga uppsättningar. Tillåt knä/björn-alternativ.
- **newCoachOk:** true
- **watchForRequired:** true

### 27. Stå-på-huvud-utmaning
- **Duration:** ~5 min
- **Summary:** Huvudstående-utmaning med fokus på trygg upp-/nedgång.
- **How:** Triangelbas, madrass, gärna mot vägg först. Utmana tid med bra form. Spotting för dem som är nya.
- **Watch for:** Belastning på nacke/huvud — avbryt vid smärta; aldrig utan madrass; ingen som “knuffar upp” andra.
- **newCoachOk:** true
- **watchForRequired:** true

### 28. Mörkerkurragömma
- **Duration:** ~8–12 min
- **Summary:** Kurragömma med dämpad belysning / mörker i hallen.
- **How:** Tydliga regler innan ljuset skruvas ner: var man får gömma sig, var man inte får (förråd, redskapsskåp, ovanpå plintar som kan tippa), hur man blir “tagen”, när ljuset tänds igen. Behåll nöd-/utgångsljus enligt hallens krav. Räkna in alla efteråt.
- **Watch for:** Fall i mörker; gömställen under tunga redskap; rädsla — erbjud “ljusvakt”-roll. Räkna in hela gruppen innan ni lämnar.
- **newCoachOk:** true
- **watchForRequired:** true
