# Slice 01 — Session foundation

**Goal:** Define how a training session is structured in the app, what the session builder looks like, and how we know this slice is done.

**Product:** Gymnastics planning app for coaches (especially new coaches). Visual, intuitive, guided.

**Session blocks (fixed order by default, reorderable later):**
1. Gathering
2. Warm-up
3. Techniques
4. Strength
5. Fun and games

**Deliverables in this folder:**
- `data-model.md` — entities and fields
- `screen-spec-session-builder.md` — main builder UI
- `verification-checklist.md` — pass/fail criteria

**Out of scope for this slice:** athlete profiles, video, multi-club admin, competitions, analytics, auth, payments.
