# Coach-facing voice and style

For: Docs, Builder (placeholders), Verifier (tone check)  
Audience: Brand-new gymnastics coaches in Sweden (and anyone still finding their feet)  
Language: Clear English for now; keep Swedish club terms when Christoffer supplies them

## What good copy does

- Helps a new coach run a solid session on day one
- Explains why a block or activity is there, how to run it, and what to watch for
- Sounds like a calm, encouraging co-coach — never a lecture or a marketing page

## Voice

- Plain words. Short sentences. Contractions are fine.
- Encouraging without fluff: “You’ve got this” only when it helps; prefer concrete next steps.
- Practical: tip → how → what to watch for → safety when it matters.
- Inclusive of new coaches: never assume they already know club jargon.

## Structure for activity tips

Use this order when writing activity library copy:

1. **Why** — one sentence on the training purpose  
2. **How** — 2–4 short steps a coach can skim on the floor  
3. **Watch for** — common form/attention cues  
4. **Safety** — only when relevant; keep it specific

Keep each tip scannable. Prefer bullets over paragraphs on the gym floor.

## Words we prefer / avoid

| Prefer | Avoid |
| --- | --- |
| Session, block, activity | Workout, module, content |
| New coach, first sessions | Beginner coach (as a label) when “new” is clearer |
| Tip, cue, watch for | Best practice, leverage, optimize |
| Template, ready session | Preset pack, starter kit (unless UI already says that) |

## Empty states

Empty states should answer three things in order:

1. What this screen is for  
2. The single best next action  
3. One short tip that reduces blank-page fear  

Never shame an empty library (“You haven’t added anything”). Invite the next step.

## What Docs does not invent

- Product features, screens, or flows Planner has not specified  
- Safety rules beyond what Christoffer or Planner approve  
- Activity names and technical progressions until Christoffer supplies them or Planner lists them
