# Slice 02 — Phone / small-screen polish

**Goal:** A new coach can plan a full pass comfortably on a phone (~390×844) without horizontal scroll, tiny tap targets, or losing the library/tips/templates.

**In scope:** Responsive layout + touch-friendly chrome for Home and Passbyggaren. Swedish copy unchanged unless a label must shorten for width.

**Out of scope:** New features, new activities, export, drag-and-drop, tablet-only redesign, dark mode.

**Baseline:** Slice 01 desktop/tablet-first; one breakpoint already stacks the builder grid at ≤900px. Slice 02 makes **≤480px** (and ≤768px) feel intentional.
