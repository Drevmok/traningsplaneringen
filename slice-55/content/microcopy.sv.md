# Slice 55 — texter (FÖRESLAGEN)

Inga nya texter med ★-vägen. Befintliga texter visas på ett nytt ställe.

| Nyckel | Text | Ändring |
|---|---|---|
| `passLength` | Passlängd | Rubrik även på mallvägen (B1) |
| `passLengthMinutes` | min | Knapparna 60 / 90 / 120 min, som i Frågor-vägen |
| `wizardStepProgress` | Fråga {n} av {total} | Mallvägen blir «Fråga 3 av 3» |
| `clubTemplateApplied` | (oförändrad) | Toasten efter start, som i dag |

Låsta termer oförändrade: Starta från mall, Passbyggaren, Biblioteket, pass, gymnaster.
